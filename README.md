## Project Description
This project is designed to manage laboratory equipment, equipment bookings, and maintenance records using a MySQL database. It provides a Flask-based web interface for viewing, inserting, and deleting records, along with SQL reports and business-rule validation.

## Repository Structure
- **Presentation-I/** — Initial project design and database planning.
- **Presentation-II/** — Database schema, SQL queries, and presentation materials.
- **Presentation-III/** — Flask application, source code, screenshots, and presentation files.
- **Project-Report/** — Final project report in PDF format.

## Technologies Used
- MySQL
- Python
- Flask
- HTML and CSS
- GitHub

## How to Run
1. Install the required Python packages using `pip install -r requirements.txt`.
2. Configure the MySQL connection in `Presentation-III/config.py`.
3. Make sure the `laboratory_management` database exists and MySQL is running.
4. Run `python app.py` from the `Presentation-III` folder.
5. Open `http://127.0.0.1:5000` in your browser.

Refer to the README inside `Presentation-III/` for additional setup instructions.
